# 对于开发者

我们欢迎所有愿意为 JNU-EXAM 项目贡献代码、修复问题或提出建议的开发者。无论你是第一次参与开源项目，还是经验丰富的贡献者，我们都期待你的加入。

## 如何开始？

选择一个想要进行贡献的方向：

- PC 端下载器
- 安卓端下载器
- 搭建新的下载源

### PC 端下载器

开源链接: https://github.com/gubaiovo/JNU-EXAM-Downloader  
你可以提交 pr，也可以直接找群主

### 安卓端下载器

开源链接：https://github.com/KuLiPai/JNU-EXAM-Client  
你可以提交 pr，也可以直接找管理员`3290675192`

### 搭建新的下载源

具体内容查看：[搭建下载源](/developer/build_own_source)
