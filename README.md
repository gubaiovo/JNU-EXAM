### 📚 简介

JNU-EXAM 是一个致力于解决江南大学校内考试资料获取难、信息不对称问题的开源项目。

我们通过自动化工作流将收集到的资料进行格式化、水印处理，并分发至各个下载源，确保可以在任何网络环境下都能获取所需的复习材料

### 📂 目录结构

```
JNU-EXAM/
├── data/                    # 核心资料
│   ├── 科目/
│   ├── 其他学校/
│   └── ...
├── doc/                     # 文档网站源码
├── LICENSE                  # 开源协议
├── README.md                # 项目介绍
├── directory_structure.json # 资源索引
└── source_list.json         # 下载源列表
```


### 🤝 贡献
